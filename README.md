# สำนัก — เว็บเช็คชื่อ

เว็บแอปเช็คชื่อธีมดำแดง มี 4 หน้า:

1. **ภาพรวม** (สาธารณะ ดูอย่างเดียว) — แสดงรายชื่อสมาชิกทั้งหมดในสำนัก แต่ละคนมีป้ายตำแหน่งกำกับ
2. **เช็คชื่อ** (ต้องกรอกรหัสผ่าน) — เลือกวันที่ แล้ววาง/พิมพ์รายชื่อคนที่มา ระบบจะจับคู่กับทำเนียบสมาชิกให้อัตโนมัติ พร้อมตัวนับ "เช็คแล้ว X/Y คน"
3. **จัดการสมาชิก** (ต้องกรอกรหัสผ่าน) — เพิ่ม/แก้ไข/ลบ สมาชิกในทำเนียบ คนที่เพิ่มตรงนี้จะไปโผล่หน้าภาพรวมทันที
4. **รายงาน** (ต้องกรอกรหัสผ่าน) — เลือกช่วงวันที่แล้วดึงรายงานเช็คชื่อ ระบบจะแยกเป็นตารางรายสัปดาห์ให้อัตโนมัติ (ชื่อ / ตำแหน่ง / คอลัมน์วันที่มีคนเช็คชื่อ / รวม) เหมือนตารางที่เคยทำมือใน Google Sheets — ดูพรีวิวในเว็บได้เลย หรือกดดาวน์โหลดเป็นไฟล์ Excel (.xlsx) ก็ได้ ถ้าเลือกช่วงยาวหลายสัปดาห์ ไฟล์จะรวมทุกสัปดาห์ไว้ในไฟล์เดียว พร้อมชีต "สรุปรวม" ที่รวมยอดทุกสัปดาห์ของแต่ละคนไว้ในตารางเดียว

หน้า "เช็คชื่อ", "จัดการสมาชิก" และ "รายงาน" ใช้รหัสผ่านเดียวกัน กรอกถูกครั้งเดียวก็ปลดล็อกทั้งสามหน้าให้เลย (ไม่ต้องกรอกซ้ำ)

## สถานะ "เข้ามาใหม่" (ใหม่)

- ไปที่หน้า **"จัดการสมาชิก"** (หน้า 3) ในตาราง "รายชื่อสมาชิกทั้งหมด" จะมีคอลัมน์ "สถานะ" เพิ่มมา
- กดปุ่ม **"ตั้งเป็นเข้ามาใหม่"** ที่แถวของคนนั้น → จะมีป้ายทอง "เข้ามาใหม่" ขึ้นข้างชื่อคนนั้นในหน้า **"ภาพรวม"** (หน้า 1) ทันที
- กดปุ่ม **"เอาออก"** ที่แถวเดิม → ป้ายจะหายไปจากหน้า 1 ทันที ไม่มีอะไรค้างเลย
- รองรับตั้งค่าได้ทีละคน ยังไม่มีสถานะอื่นนอกจาก "เข้ามาใหม่" (ถ้าต้องการเพิ่มสถานะแบบอื่นในอนาคต แก้ที่ตัวแปร `STATUSES` ใน `server.js`)

## เกี่ยวกับหน้า "รายงาน" (ใหม่)

- เลือก **จากวันที่ / ถึงวันที่** หรือกดปุ่มลัด "สัปดาห์นี้" / "สัปดาห์ที่แล้ว" / "เดือนนี้" / "รวมทั้งหมด"
- ระบบจะตัดช่วงที่เลือกเป็นสัปดาห์ (จันทร์–อาทิตย์) อัตโนมัติ และแสดงเฉพาะ "วันที่มีคนเช็คชื่อจริง" เป็นคอลัมน์ (วันไหนไม่มีใครเช็คชื่อเลยจะไม่โผล่ในตาราง เหมือนตารางเดิม)
- แต่ละแถวคือ 1 คน มีคอลัมน์วันที่ (1 = มา, 0 = ไม่มา) และคอลัมน์ "รวม" ท้ายแถว
- ถ้าเลือกช่วงที่มีมากกว่า 1 สัปดาห์ หน้าเว็บจะแสดงตารางแยกทีละสัปดาห์ต่อกันลงมา บวกตาราง "สรุปรวมทุกสัปดาห์" ด้านล่างสุด (คอลัมน์ = แต่ละสัปดาห์ + รวมทั้งหมด)
- ปุ่ม **ดาวน์โหลด Excel (.xlsx)** จะสร้างไฟล์ที่มี 2 ชีต: `รายสัปดาห์` (ตารางแยกทีละสัปดาห์ ไล่ลงมาในไฟล์เดียว มีสีเขียว/แดงกำกับเหมือนเช็คชื่อจริง) และ `สรุปรวม` (ตารางสรุปยอดทุกสัปดาห์ของแต่ละคน)
- ดึงจากตาราง `checkins` จริงในฐานข้อมูล ไม่ต้องพิมพ์ซ้ำ ไม่ต้องทำมือใน Google Sheets อีกต่อไป

โครงสร้าง: Node.js/Express เสิร์ฟทั้ง API และหน้าเว็บ เชื่อมต่อฐานข้อมูล MariaDB บน Aiven

## ไฟล์ในโปรเจกต์

```
server.js         → API + เสิร์ฟไฟล์หน้าเว็บ (รวม API รายงาน /api/report, /api/report/export)
package.json      → รายการ dependency (express, mysql2, exceljs)
schema.sql         → คำสั่งสร้างตาราง members, checkins (server.js สร้างให้อัตโนมัติอยู่แล้ว)
.env.example       → ตัวอย่างตัวแปรเชื่อมต่อฐานข้อมูล
public/index.html  → หน้าเว็บ (4 แท็บ: ภาพรวม / เช็คชื่อ / จัดการสมาชิก / รายงาน)
public/style.css   → ธีมดำแดง
public/app.js      → ลอจิกฝั่งหน้าเว็บ
```

## โครงสร้างฐานข้อมูล

- `members` — ทำเนียบสมาชิกถาวร (id, name, rank)
- `checkins` — บันทึกว่าใครเช็คชื่อวันไหน (member_id, checkin_date) — ลบสมาชิกออกจาก `members` จะลบประวัติเช็คชื่อของคนนั้นไปด้วยอัตโนมัติ

> หมายเหตุ: โปรเจกต์เวอร์ชันก่อนหน้าเคยมีตาราง `attendance` (เก็บชื่อ+วันที่รวมกันแบบเดิม) เวอร์ชันนี้เปลี่ยนโครงสร้างใหม่ทั้งหมด ข้อมูลเก่าในตาราง `attendance` จะยังอยู่ในฐานข้อมูลแต่ไม่ถูกใช้งานแล้ว ต้องเพิ่มรายชื่อสมาชิกใหม่ผ่านหน้า "จัดการสมาชิก"

## 1) เตรียมฐานข้อมูลบน Aiven

ใช้ฐานข้อมูลเดิมที่เชื่อมต่ออยู่แล้วได้เลย ไม่ต้องสร้างใหม่ — พอ deploy เวอร์ชันนี้ server จะสร้างตาราง `members` และ `checkins` ให้อัตโนมัติตอนสตาร์ท

## 2) รันทดสอบบนเครื่องตัวเอง (ถ้าต้องการ)

```bash
npm install
cp .env.example .env   # แล้วใส่ค่าจริงจาก Aiven ลงไป
node -r dotenv/config server.js   # หรือใช้ package "dotenv" / export ตัวแปรเองก่อนรัน
```

## 3) วิธี push ขึ้น GitHub (แล้ว Render จะ deploy ให้เองอัตโนมัติ)

**สำคัญ:** แค่ดาวน์โหลดไฟล์มาเก็บไว้ในเครื่องเฉยๆ ยังไม่มีผลอะไรกับเว็บที่รันอยู่จริง ต้อง push ไฟล์ขึ้น GitHub repo เดิม (`PhakkhapornVir1928/ETERNAL` branch `main`) ก่อน Render ถึงจะเห็นการเปลี่ยนแปลงแล้ว deploy ให้ใหม่ ไม่งั้นเว็บจะยังเป็นโค้ดเวอร์ชันเก่าอยู่แบบเดิมทุกครั้ง

### วิธีที่ 1 — ใช้คำสั่ง git (ถ้ามี git ลงเครื่องแล้ว และเคย clone repo นี้ไว้)

1. เปิด Terminal / Git Bash แล้ว `cd` เข้าไปในโฟลเดอร์ repo ที่ clone ไว้ (โฟลเดอร์ที่มี `.git` อยู่ข้างใน)
2. แตกไฟล์ zip ที่ได้ แล้ว**คัดลอกไฟล์ทั้งหมดไปทับ**ไฟล์เดิมในโฟลเดอร์ repo (ทับ `server.js`, `public/`, `README.md`, ฯลฯ)
3. รันคำสั่งตามลำดับ:

```bash
git add .
git commit -m "เพิ่มหน้าเช็คชื่อและจัดการสมาชิกใหม่"
git push origin main
```

4. ถ้าเป็นการ push ครั้งแรกจากเครื่องนี้ อาจมีหน้าต่างให้ login GitHub ขึ้นมา ให้ login ให้เรียบร้อยก่อน
5. เข้าไปดูที่ [dashboard.render.com](https://dashboard.render.com) → service `ETERNAL` → แท็บ **Events** จะเห็นการ deploy รอบใหม่กำลังรันอยู่ รอสัก 1-2 นาทีแล้วรีเฟรชเว็บ

> ถ้ายังไม่เคย clone repo มาลงเครื่องเลย ให้รันคำสั่งนี้ก่อน (เปลี่ยน URL เป็นของ repo ตัวเอง):
> ```bash
> git clone https://github.com/PhakkhapornVir1928/ETERNAL.git
> cd ETERNAL
> ```
> แล้วค่อยเอาไฟล์ใหม่ไปทับ แล้วทำตามขั้นตอนข้างบน

### วิธีที่ 2 — อัปโหลดผ่านเว็บ GitHub โดยตรง (ไม่ต้องลง git)

1. เข้า repo ที่ [github.com/PhakkhapornVir1928/ETERNAL](https://github.com/PhakkhapornVir1928/ETERNAL)
2. เข้าไปทีละโฟลเดอร์/ไฟล์ที่ต้องแก้ (`server.js`, `public/index.html`, `public/app.js`, `public/style.css`, `README.md`, `schema.sql`) กดไอคอนดินสอ (Edit) มุมขวาบนของไฟล์ แล้ววางเนื้อหาใหม่ทับของเดิม จากนั้นกด **Commit changes** ทีละไฟล์
   - หรือถ้าอยากอัปโหลดทีเดียว: กดปุ่ม **Add file → Upload files** ที่หน้า repo แล้วลากไฟล์ที่แตกจาก zip ไปวาง (มันจะถามว่าจะทับไฟล์เดิมไหม กด **Commit changes** ยืนยันได้เลย)
3. พอ commit เสร็จ Render จะ auto-deploy ให้เองภายในไม่กี่นาที (เช็คได้ที่แท็บ Events เหมือนวิธีที่ 1)

## เกี่ยวกับรหัสผ่าน

รหัสผ่านตอนนี้คือ `admin123` เช็คฝั่งหน้าเว็บ (client-side) เท่านั้น ไม่ได้ผูกกับระบบล็อกอินหรือ session ใด ๆ — เหมาะสำหรับกันคนพลาดเข้าไปกดผิด แต่**ไม่ได้ป้องกันคนที่ตั้งใจหลบเลี่ยง** เพราะ API เพิ่ม/แก้/ลบข้อมูลไม่มีการตรวจรหัสผ่านฝั่ง server

รหัสผ่านอยู่ในไฟล์ `public/app.js` ตัวแปร `GATE_PASSWORD` แก้ไขตรงนั้นได้เลยถ้าอยากเปลี่ยน
